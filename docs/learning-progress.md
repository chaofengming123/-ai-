## 第 7 课

- api 模块提供等待 1 秒的 Promise，可显式模拟失败；未发送网络请求。

- 首次加载前不显示误导性的 0 或空结果，重载失败保留旧记录。
- 模拟数据源保留本次新增记录，重新加载不丢失，整页刷新仍重置。
- 关键代码解释与小练习见 `lesson-07.md`。
- 验证通过：构建、首次加载反馈、模拟失败与重试、旧记录保留；store 检查覆盖首次失败恢复、重复加载拦截、加载中禁止创建、重新加载保留新建记录。
