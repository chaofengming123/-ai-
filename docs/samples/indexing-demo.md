# 知识平台使用说明

## 上传文档

进入文档管理，选择所属知识库，再选择文件并点击上传。支持 TXT、Markdown、PDF 和 DOCX，文件不能超过 5 MB。上传成功说明原始文件已经保存，可以下载检查内容。

## 建立索引

编辑者或管理员可打开文档索引面板，手动建立索引。后端提取文字并分块，调用向量模型，然后保存到 Qdrant。本课提取正文最多 4000 字符，超出时需要先拆分文件。

## 账号与权限

普通用户可以查看知识库、下载文档和查看索引状态。编辑者可以上传文件并建立索引。管理员负责知识库管理与授权。项目密码和 Mac 系统登录密码分别用于不同的登录入口。

## 常见问题

扫描 PDF 可能只有图片，没有可解析的文字，需要先做 OCR。建立索引失败时，检查模型配置、网络以及 MinIO 和 Qdrant 的运行状态。重新建立失败不会删除上一次成功的索引。
