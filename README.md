# 企业 AI 知识管理平台

从零逐步实现 Vue 3 + Spring Boot 企业知识管理与 RAG 问答系统。

当前仅完成工程目录与学习资料初始化，尚无可运行的应用。

## 目录

- `frontend/`：Vue 3 + JavaScript + Vite 前端。
- `backend/`：后续 Spring Boot 后端。
- `docker/`：后续容器与部署配置。
- `docs/`：学习手册与进度记录。

空目录使用 `.gitkeep` 保留，开始实现时可删除对应占位文件。

## 下一步

创建 Vue 3 + JavaScript + Vite 前端，先用 Mock Data 实现侧边导航和知识库列表，再按手册逐步增加功能。
